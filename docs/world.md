# 基调
三个关键词：**梦境、时代、荣格**

**梦境**：这是世界的核心设定。世界被分为清醒时现实的世界，以及入梦时的梦境世界。事实上，梦境世界不能单纯的理解为梦，而是存在于另一个位面的世界，要进入它的方式就是做梦。两个世界会有交集，相互影响，在平时这种影响微乎其微，然而一旦发生什么大事，世界之间的影响会变得显现出来。

**时代**：这是故事的发生时间。故事会以碎片化呈现，并且由网状连接。每个时代存在着不同的命题和事件，有着不同的角色与故事。一旦将它们拼凑起来，便能够获得一张完整的地图。

**荣格**：卡尔·古斯塔夫·荣格，瑞士心理学家，他的理论将会成为故事设定的根基。阿尼玛（Anima）、阿尼姆斯（Animus）、共时性、集体潜意识……荣格给我们留下了太多可以用来创作的「遗产」。

**世界基调**：简单来说是一个「低魔」的世界，存在所谓的「魔法」或「异能」，但都发生在梦境世界当中而不是现实世界。在常识的世界中，一切都与我们的现实无异，而在梦中，一切又在悄然发生着。

# 意识、个人无意识、集体无意识
集体无意识（collective unconscious）是由瑞士心理学家卡尔·古斯塔夫·荣格所提出的整体性的心理架构概念。荣格认为人可以分层三个层次，由浅到深为：**意识、个人无意识和集体无意识**。
<br>倘若我们的世界是一座飘在海里的冰山。在水平面之上的便是**意识**，也就是我们常识的世界。所有人都生活在这里，遵循物理定律、社会规则、历史进程——和我们的现实没有任何区别。
<br>而「做梦」便是将实现潜入到水平面之下，来到了**无意识**的大海之中，这里是另一个世界，另一个维度。所有人每晚都会自然下沉到这个区域，但大多数人只是随波逐流，被水流裹挟着移动，无法控制方向。
<br>越往海的深处走便越原始，越神秘，越不受现实与理性所掌控。
<br>在最深处，有着坚固的海床，这里便是**集体无意识**。这里没有个人。你进入后，不再是你自己，而是人类的「某一种可能性」。在这里，有着人类最为原始原初的意向。

# 利维坦
**利维坦**（Leviathan）并非是某个生物。祂在集体潜意识的维度里，没有形体，或者说祂的形体就是「原始混沌」本身。一些记载中为了理解和描绘祂，常将其比作一只鲸鱼，但这并非代表利维坦的真实样貌。
<br>祂所做的事情便是不断地常识撞击「冰山」，也就是我们常识的世界。这种攻击出自祂的本能。但由于我们的现实实在是太过于坚硬了，随着科学的发展，神话和神秘主义逐渐被打压，导致增强了「冰山」的力量。
<br>利维坦的攻击几乎就是徒劳。偶有效果就会导致现实世界出现一些差错，例如曼德拉效应、既视感、创作者灵感的顿悟甚至是集体幻觉等等，都可以看作利维坦攻击「冰山」所导致的现象。

# 历史天使
**历史天使**（Angel of History），祂的职责便是守护集体潜意识的秩序，如若把一切都比作一个系统的话，祂便是集体无意识的自我防御机制，像是系统里的杀毒软件，为了消除那些妄图更改集体无意识的行为。
<br>祂不恨入侵者，也不爱被保护者，祂只是在执行功能。当有人试图在集体无意识中做危险的事，祂会出现并阻止。例如有人潜入某个历史事件的沉积层，试图改变「那个事件在集体心理中留下的模式」，亦或是有人想彻底抹除「恐惧」或「爱」的原型，或者通过大规模叙事操控，强行向集体无意识中植入一个原本不存在的心理模式……这些都会被历史天使判断为有害于「系统」的行为。

# 亚当·喀德蒙
**亚当·喀德蒙**（Adam Kadmon）是「最初的亚当」——一个完美的、原初的、包含一切可能性的「巨人」。祂不是后来的地上的亚当，而是天上的亚当，是万物的原型模板，是「人类之人类」。祂就是梦境本身。所有人类的梦，都是祂的「呼吸」。
<br>祂的力量过于渺小，从不主动彰显自己。祂的能力是将梦中的东西变为现实，或者更进一步说，让梦境替代现实。

## 捕梦者
**捕梦者**（Dreamcatcher）一个古老的团体，从人类刚刚开始做梦时就已经存在。他们信奉梦神亚当·喀德蒙，并且认为现实的世界是一个不完满的世界，只有彼岸世界也就是梦境中的世界才是真正的故乡。如今说捕梦者是一个组织并不合理，因为随着历史的演变，捕梦者分散世界各地，并且并不总是相互为伍，甚至内部还存在对立。
<br>捕梦者们们具有一种古老的圣遗物：**星丛**（konstellation）。星丛可以帮助他们潜入集体无意识的深海，并且打捞集体无意识的梦境碎片，滋养他们的神明，为了有朝一日能够抵达彼岸世界。
<br>时至今日，捕梦者们已经无法组成较大的组织，而是散兵游勇，各自为战。现在的捕梦者们并非都是信奉亚当·喀德蒙，甚至有的捕梦者都不知道祂的存在。捕梦者的星丛都是从上一代捕梦者传承而来，但是有些捕梦者已经放弃了使命或根本就没有认可过使命，也就并没有让自己的子女继承。
<br>总的来说，捕梦者是一盘散沙。但在星丛的帮助下，进入集体无意识的深海来去自如，并且具有星丛所提供的强大力量。

## 筑础会
**筑础会**（Foundation of the Bedrock）最初只是一个秘密结社，成员们不允许历史以及集体无意识遭到任何形式的修改。
<br>他们是历史进步主义者，认为那些支撑着我们今时今日的地基，就是过去无数的历史碎片形成的地基。一旦地基被破坏，人类文明的大厦便会轰然倒塌。他们坚信自己是拯救人类文明的弥赛亚和守护者。
<br>现如今组织度最高的组织，表面上组织内的成员都是社会各界精英，设立并掌控着工业、科技公司、基金会等组织。

## 代达罗斯工业
**代达罗斯工业**（Daedalus Industrial）是筑础会下属的工业公司，主要为组织生成工业器械。

## 原始之潮
**原始之潮**（Primal Tide）由宗教信徒组织建立。他们认为，如今科学以及过度发展了，一切都变成了被科学解释的东西。而人类的神话、神秘主义、传说、宗教等才是人类的精神根源。
<br>他们反对科学（程度不同），反对科学实在论，有自然主义的倾向。
<br>他们是宗教性质最浓厚的组织，并且明确信奉**利维坦**
