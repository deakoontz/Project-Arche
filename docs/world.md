# 基调
三个关键词：**梦境、时代、荣格**

**梦境**：这是世界的核心设定。世界被分为清醒时现实的世界，以及入梦是的梦境世界。事实上，梦境世界不能单纯的理解为梦，而是存在于另一个位面的世界，而要进入它的方式就是做梦。两个世界会有交集，相互影响，在平时这种影响微乎其微，然而一旦发生什么大事，世界之间的影响会变得显现。

**时代**：这是故事的发生时间。故事会以碎片化呈现，并且由网状连接。每个时代存在着不同的命题和事件，有着不同的角色与故事。一旦将它们拼凑起来，便能够获得一张完整的地图。

**荣格**：卡尔·古斯塔夫·荣格，瑞士心理学家，他的理论将会成为故事设定的根基。阿尼玛（Anima）、阿尼姆斯（Animus）、共时性、集体潜意识……荣格给我们留下了太多可以用来创作的「遗产」。

**世界基调**：简单来说是一个「低魔」的世界，存在所谓的「魔法」或「异能」，但都发生在梦境世界当中而不是现实世界。在常识的世界中，一切都与我们的现实无异，而在梦中，一切又在悄然发生着。

# 意识、个人无意识、集体无意识
集体无意识（collective unconscious）是由瑞士心理学家卡尔·古斯塔夫·荣格所提出的整体性的心理架构概念。荣格认为人可以分层三个层次，由浅到深为：**意识、个人无意识和集体无意识**。
倘若我们的世界是一座飘在海里的冰山。在水平面之上的便是**意识**，也就是我们常识的世界。所有人都生活在这里，遵循物理定律、社会规则、历史进程——和我们的现实没有任何区别。
而「做梦」便是将实现潜入到水平面之下，来到了**无意识**的大海之中，这里是另一个世界，另一个维度。所有人每晚都会自然下沉到这个区域，但大多数人只是随波逐流，被水流裹挟着移动，无法控制方向。
越往海的深处走便越原始，越神秘，越不受现实与理性所掌控。
在最深处，有着坚固的海床，这里便是**集体无意识**。这里没有个人。你进入后，不再是你自己，而是人类的「某一种可能性」。在这里，有着人类最为原始原初的意向。

# 利维坦
**利维坦**（Leviathan）并非是某个生物。祂在集体潜意识的维度里，没有形体，或者说祂的形体就是「原始混沌」本身。一些记载中为了理解和描绘祂，常将其比作一只鲸鱼，但这并非代表利维坦的真实样貌。
祂所做的事情便是不断地常识撞击「冰山」，也就是我们常识的世界。这种攻击出自祂的本能。但由于我们的现实实在是太过于坚硬了，随着科学的发展，神话和神秘主义逐渐被打压，导致增强了「冰山」的力量。
利维坦的攻击几乎就是徒劳。偶有效果就会导致现实世界出现一些差错，例如曼德拉效应、既视感、创作者灵感的顿悟甚至是集体幻觉等等，都可以看作利维坦攻击「冰山」所导致的现象。

# 历史天使
**历史天使**（Angel of History），祂的职责便是守护集体潜意识的秩序，如若把一切都比作一个系统的话，祂便是集体无意识的自我防御机制，像是系统里的杀毒软件，为了消除那些妄图更改集体无意识的行为。
祂不恨入侵者，也不爱被保护者，祂只是在执行功能。当有人试图在集体无意识中做危险的事，祂会出现并阻止。例如有人潜入某个历史事件的沉积层，试图改变「那个事件在集体心理中留下的模式」，亦或是有人想彻底抹除「恐惧」或「爱」的原型，或者通过大规模叙事操控，强行向集体无意识中植入一个原本不存在的心理模式……这些都会被历史天使判断为有害于「系统」的行为。

# 亚当·喀德蒙
**亚当·喀德蒙**（Adam Kadmon）是「最初的亚当」——一个完美的、原初的、包含一切可能性的「巨人」。祂不是后来的地上的亚当，而是天上的亚当，是万物的原型模板，是「人类之人类」。祂就是梦境本身。所有人类的梦，都是祂的「呼吸」。
祂的力量过于渺小，从不主动彰显自己。祂的能力是将梦中的东西变为现实，或者更进一步说，让梦境替代现实。
